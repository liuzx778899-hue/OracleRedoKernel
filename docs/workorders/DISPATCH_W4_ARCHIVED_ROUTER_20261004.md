2. 在声明范围内自主发现目标完整XID；一个事务触及范围外原始undo时不能偷偷跳过head节点，要明确不支持/拒绝结果。任何被丢弃候选都必须有对象/容器/窗口依据，不因decoder抛错而跳过。

4. 相关窗口中未知opcode/页维护/未支持控制、原始项在叶窗口外、跨块关联未支持等保持明确拒绝。不得因已有结构scan、最终SQL相等或head空就忽略它们。
